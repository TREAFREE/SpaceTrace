# SpaceTrace 视觉设计系统

状态：**基础层已实现**

最近验证：2026-08-10

英文源文档：[visual-design-system.md](visual-design-system.md)。

## 产品气质

SpaceTrace 应当显得精确、克制、重视隐私，并且像一款原生 macOS 软件。视觉优化必须帮助用户理解证据层级，不能让不完整数据显得更确定。

设计遵循四条规则：

1. 证据和运行状态比装饰更醒目；
2. 完整、部分、不可用和失败状态除了颜色以外，始终保留文字或符号；
3. 系统材质与语义颜色会适配外观和“增强对比度”；
4. macOS 15.6 最低版本优先于仅 macOS 26 可用的视觉 API。

## 字体与排版

SpaceTrace 使用系统字体栈。这样可以保留高质量中文回退、动态字体、VoiceOver 发音和系统文字渲染，不需要捆绑第三方字体。

| 角色 | SwiftUI Token | 用途 |
| --- | --- | --- |
| 页面主标题 | `Font.spaceTraceHero` | 每页唯一的产品主张 |
| 分区标题 | `Font.spaceTraceSectionTitle` | 主要卡片与运行状态 |
| 卡片标题 | `Font.spaceTraceCardTitle` | 局部状态和列表标题 |
| 指标 | `Font.spaceTraceMetric` | 容量及可比较数字证据 |
| 正文/说明 | 系统语义字体 | 解释、来源与限制说明 |

页面主标题和结构标题采用圆角系统字形；长正文继续使用默认系统阅读字形。容量指标采用等宽数字，刷新数值时不会出现明显的宽度跳动。

## 颜色与材质

- 浅色模式使用深证据蓝，深色模式使用更明亮的蓝青色。
- 页面背景是在系统窗口背景上叠加克制的主题色渐变。
- 主要面板使用 `regularMaterial`，面板内的证据区域使用系统控件背景。
- 开启“增强对比度”后，边框会自动加深和加粗。
- 绿色、橙色和红色保留系统状态语义，但不会单独承担信息表达。

实现集中在 `SpaceTrace/SpaceTraceDesign.swift`。概览、授权、历史和菜单栏共同使用一套 Token，不再各自定义卡片样式。

## App 图标

图标由三层存储结构和一条连续轨迹组成，不包含文字、商标角色或“清理/删除”隐喻。主图为原创生成位图，随后在本机完成色键透明化、Alpha 校验，并生成从 16 px 到 1024 px 的完整 macOS 图标矩阵。

生成规范：

> 为重视隐私的空间变化追踪工具制作高级原生 macOS 图标；单个深夜蓝圆角图标块；蓝色/青色轨迹围绕三层存储轮廓；冷静、精确，在 16 px 下仍可识别；不包含文字、字母、Apple 标志、Finder 面孔、水印或多余物体。

提交的主图和派生尺寸位于 `SpaceTrace/Assets.xcassets/AppIcon.appiconset`。

## 无障碍与兼容性

- 字体使用语义文字样式，不使用固定点数。
- 装饰性图标和渐变对 VoiceOver 隐藏。
- 相关状态按 Mac 的容器优先方式分组，同时不隐藏可操作控件。
- 控件保留文字标签、测试标识、键盘快捷键和悬停帮助。
- 材质与语义颜色适配浅色/深色模式及系统对比度。
- 不使用 `.glassEffect()` 或其他仅 macOS 26 可用的 API。

## 验证

2026-07-31 完成：

- 使用独立 bundle identity 的临时签名沙盒 App，在默认 1080 × 720 窗口下渲染已授权概览，人工检查视觉层级、裁切和图表布局；
- 人工检查 1024 px、128 px 和 32 px 图标；十个资产槽位的像素尺寸与 Alpha 通道均正确；
- App 单元测试通过；
- `make verify` 通过，覆盖架构检查、37 个 suite 的 244 个 package 测试、严格并发、App 测试及 Debug/Release 构建；
- 当日 UI 测试在执行任何断言前无法建立自动化会话，因此只保留为历史阻塞证据，不会在之后被追溯改写成通过。

2026-08-10，Xcode 26.1.1 使用本机 ad-hoc “Sign to Run Locally” 签名，成功启动真实 macOS UI runner 与 App Sandbox 应用。`DirectoryAuthorizationUITests` 的 8 个受控场景在 macOS 26.5.2 上全部通过，覆盖已授权、stale、外置卷不可用、多目录、不伪造历史以及未配置状态。聚焦的辅助功能断言证明：主要目录操作，以及已授权目录的更换/移除操作具有稳定名称且可点击；授权状态说明与“只读、移除授权不删除文件”的隐私边界也存在于 macOS 可访问性 value 树中。

这只是当前主机上的自动化 fixture 证据，不代表已经完成人工 VoiceOver 朗读检查、Full Keyboard Access 遍历、增强对比度/减少动态效果/更大系统文字视觉检查，也不代表具备稳定 Apple 签名身份、验证了真实 Powerbox/bookmark，或完成 macOS 15.6 运行资格。这些仍属于发布矩阵门禁。
